# 移动测量记录模板

每组实验至少记录 5 次，报告均值、范围和测量误差。区分显示帧率与游戏逻辑帧率；像素需要相同摄像机缩放。

| 字段 | 记录 |
| --- | --- |
| SWF SHA256 / 版本 | |
| Ruffle/Flash 版本、OS、显示 FPS | |
| 录像路径、分辨率、录制 FPS、缩放 | |
| 场景、起点、职业、武器、装备 | |
| 输入序列、预热和重复次数 | |
| 起跳 / 顶点 / 落地帧 | |
| 起点 / 顶点 / 落点 x y 像素 | |
| +最大速度到 -最大速度帧数 / 位移 | |
| 上升及下降空中转向响应 | |
| 台阶高度、成功/失败、是否需跳跃 | |
| 重生速度和残留输入 | |
| 时间 / 高度 / 距离及误差 | |
| evidence id、OBSERVED confidence、说明 | |

时间 = 帧差 / 录制 FPS；高度 = 起始脚底 y − 顶点脚底 y。不要将渲染帧速度直接当 px/s。若推导重力，作为单独 INFERRED 记录链接测量记录。修改已知参数时追加 TUNED 记录并说明旧值、新值和理由，保留历史来源。
