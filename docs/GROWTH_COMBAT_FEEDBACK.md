# 成长模式战斗反馈迭代

本轮仅改变成长模式战斗内体验，联机和离线4v4训练共用 `OnlineScene`、反馈模型与展示层。经典和战役反馈保持原有规则。

## 命中与成长

- 服务端伤害事件携带实际生命损失、护甲消耗、盾吸收、设施损伤及爆头标记。致死伤害不超出剩余生命；同次霰弹按目标合并，避免重复显示。
- 本人命中显示0.8秒数字，120毫秒内同目标数字合并，最多24组。可见敌人显示2秒血条及0.5秒掉血拖尾；离开可见集合立即移除血条和角色伤害数字。
- 准星标记区分命中、爆头、护甲、格挡、部署物和击杀。每次本人击杀都有独立确认短音与1.5秒名称提示，3秒内再次击杀累计连杀。沿用内置音频，以不同速率和音量区分击杀、升级、选卡确认与觉醒。
- 升级横幅保留2秒，待选按钮持续显示数量。U或点击展开三选一，再按U收起；提交期间禁用重复提交，确认后显示强化名称，失败可重试。刷新候选保留展开状态，选完本批后回到紧凑状态。
- 初次进入、重连、后台恢复不补播过去的命中、击杀或升级。换弹完成、技能就绪、道具耗尽与操作失败使用轻量提示。比赛不会因打开选卡暂停，打开选卡或点击卡片时不向战场发送射击。

## 弹道与数值

- 原实现的接收缓存和绘制层均用3 tick截止，而且过滤器要求射手及枪口可见；隐藏枪口射入可见区域的整条弹道会被丢弃。
- 成长弹道使用同一客户端单调时钟控制150毫秒寿命和淡出，绘制层不再按最新快照帧重新截断。权威稳定ID用于重复快照去重。
- 服务端按16世界像素采样可见区间，仅发布可见段。隐藏起点不携带射手、队伍、枪口或原始射程；隐藏命中不携带命中目标、爆头、伤害或击杀结果。经典弹道过滤保持原逻辑。
- 突击兵基础倍率1.10，基础地面速度上限10.45。重型栓狙间隔54 tick（1.8秒），选中时倍率0.85再叠加原配件倍率，切副武器后解除。武器伤害不变。
- 内容规则版本67：旧客户端与新服务器不可混用。更新客户端与服务器必须作为同一版本发布；本轮GitHub分支推送不等同于公网部署。

## 验收入口

`growth-feedback.test.ts`覆盖实际伤害、吸收、霰弹聚合、过期、去重、可见性、重连、成长状态与数值；`growth-feedback.spec.ts`使用两个真实浏览器客户端验证互相射击及击杀反馈，并检查720p/1080p升级交互。既有成长生命周期、离线训练与8人弱网性能用例继续作为回归检查。

发布必须在本地Windows执行`npm run release`，校验便携运行时、ZIP逐文件哈希与敏感文件排除，保留时间戳包并更新latest包。
