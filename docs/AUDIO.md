# 音效与角色语音

所有游戏模式共用本地 Web Audio 播放服务。右下角“声音设置”可调整总音量、音效、语音、静音和中文字幕；设置存于 `strike.audio.v1`，在同一浏览器、同一地址下跨模式保留。首次点击或按键后启用声音；不加载音乐，不依赖在线语音服务。

## 素材与播放

- 47 个片段，54 把枪械均有开火与换弹映射。同类枪共享样本，分类依据已有原作握姿、换弹动画和 `UnitMC.reloadSound`；不是逐枪完全复刻。
- 原作提供枪声、换弹、近战、格挡、爆炸、死亡、技能、补给、目标和界面音效。选择医疗兵、刺客、突击兵、重装兵时播放原作职业短句；出战和联机调试切换职业同样支持。
- 四职业采用 6 条已核对的原作短句；再生技能采用原作 `V_k3`。其余 `V_k` 多为直升机、空袭等当前未实现的技能播报，未错误用于普通击杀。
- 脚步、起跳及落地来自 [Kenney Impact Sounds](https://kenney.nl/assets/impact-sounds)，CC0；普通击杀提示“Target eliminated.”由本机 Microsoft Zira Desktop 合成并加无线电频段处理，不克隆演员声音。
- 原作音频保留原权利归属，不声明为 CC0 或免费再分发授权。逐项来源、处理、台词、原始与输出哈希见 `public/assets/audio/manifest.json`；Kenney 许可和音频来源说明随包附带。

声音事件覆盖开火、手动及自动换弹、换弹取消、切枪、空弹、受伤、命中、死亡、复活、移动、刀盾、技能、道具、爆炸、补给、目标交付与胜负。技能／道具失败在本地玩家端提示。没有实际发生的动作不播放。

## 技术行为

`AudioService` 管理解码缓存、三路音量、左右声像、1400px 内距离衰减及总线压缩器；末端软限幅处理多人同步开火的瞬态峰值。原作采样限幅到 0.65，保留 Vorbis 解码峰值余量。最多 32 个并发音效，语音单通道；同组语音冷却 8 秒。声音变体不使用模拟随机源。音频失败只跳过样本，不阻断战斗。

`AudioPresentation` 按房间／回合／重连代数和事件 ID 去重，超过 6 个模拟帧的旧事件不播放；后台、重连和新回合重新建立事件游标。换弹带独立可取消播放标签，切枪、死亡和角色消失时停止。暂停、退出和失焦停止声音；恢复不补播积压。暂停期间声音设置仍可试听。

模拟只产生展示事件，不依赖音频服务；新增事件字段包含发生时的武器、技能、换弹帧数及爆炸位置。服务器继续过滤隐藏角色，新增坐标也须通过视野检查。霰弹一次发射仅一个声音事件。内容规则版本升至 26，联机客户端和服务端须一起更新；本轮不执行公网部署。

## 重建与验证

1. 保留已有静态原作导出 `archaeology/exported/sounds`。将 Kenney 页面中的 `kenney_impact-sounds.zip` 下载为 `archaeology/local/kenney-impact.zip`。
2. 在 Windows 运行 `powershell -NoProfile -File tools/synthesize-audio.ps1`。
3. 用 Python 运行 `tools/curate-audio.py <ffmpeg可执行文件>`；它只挑选使用的资源，生成产品音频和两个一致的清单。语音文本维护于 `tools/audio-voices.json`。
4. `npm run check` 检查边界、单元测试和生产构建；`npx playwright test tests/gameplay/audio.spec.ts` 验证所有样本实际解码、字幕、设置、训练场、联机重连及下载失败。
5. `npm run release` 生成本机 Windows x64 好友 ZIP，并用便携 Node 在空 PATH 下校验 HTTP 页面和全部音频；ZIP 按文件哈希复核。研究用模型、Python 库和原始 SWF 均不打入包。

语音核对使用本地 Whisper base.en 辅助识别和原作脚本台词对照；未将这一检查描述为真人听感验收。

2026-09-12 验证结果：`npm run check` 的 402 项单元测试通过；7 项音频浏览器用例、3 项战役、2 项调试房间及弱网短点击用例通过。八人同步连续射击经过实际 OfflineAudioContext 混音后峰值低于满幅。生产包的 4 项离线测试通过，包括阻断外网后的全部 47 个样本解码及字幕显示。Windows x64 便携运行时在空 PATH 下通过验证，好友 ZIP 共 227 个文件按哈希复核；保留时间戳版本并更新 latest ZIP。未部署公网。
