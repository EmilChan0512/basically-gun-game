# 公共调试房间

正式服务启动时注册固定的 `debug` 公共房间。联机首页点击“加入公共调试房间”，无需房间码、密码、准备或房主开局；一个玩家也可开始移动和射击，后来加入的玩家直接参战。

使用 hijack 地图和团队交火规则，最多 8 人，自动平衡队伍，保留复活。没有比赛时限，也不因分数或队伍离场结算。房间空置后保留入口并回收对局，下次加入重新创建对局。断线保留席位 30 秒供重连，过期释放。

普通自建房间仍保留原有开局和胜负规则。嵌入式测试服务可通过 startServer 的第六个参数启用公共房间，正式 server/main.ts 默认启用。协议入口为 joinDebug，仍校验客户端内容版本和昵称。

2026-09-12：公共调试对局上方常驻职业、主武器、副手、技能和战术道具选择栏，选择后立即由服务器应用，无需退出房间或准备。装备型号全部开放，但刀仅限刺客、盾仅限重装兵，技能也限制在本职业两种之内。换职业自动恢复USP及该职业默认技能；E施放技能、G使用道具，HUD显示当前技能状态/冷却与道具数量。

调试换装保留位置、队伍、击杀和阵亡统计，补满生命与弹药，重置技能/道具/盾牌和出生保护；死亡状态换装会在安全出生点恢复。服务器清除旧配装尚未执行的输入指令、本人在飞行的手雷和旧技能持续状态，其他玩家不被重置。进入选择栏时客户端清除按键/攻击状态，避免选菜单导致误射。断线重连、正常复活和可信检查点恢复均保留配装。

实时修改仅允许公共调试房间自己的受控角色；普通房间仍只能在大厅改配装，战斗中服务器拒绝修改。配装消息中的职业、武器槽位、技能、道具都独立校验，无效请求不会部分修改角色或清空输入。旧消息省略技能/道具时采用该职业默认技能和急救包。

CI现在覆盖真实浏览器的调试菜单、E/G操作与重连，并在独立打包进程中检查公共房间、实时切换及技能发动。新增单元测试验证角色隔离、清空旧输入并确认序号、技能职业限制、死亡/复活和普通房间禁用调试接口。

验证：room 单元测试覆盖单人控制、迟到参战、超时/超分不结算、连续离场席位回收；debug-room 浏览器测试覆盖服务启动注册、一键进入、切枪以及空房保留。
