# 公共调试房间

正式服务启动时注册固定的 `debug` 公共房间。联机首页点击“加入公共调试房间”，无需房间码、密码、准备或房主开局；一个玩家也可开始移动和射击，后来加入的玩家直接参战。

使用 hijack 地图和团队交火规则，最多 8 人，自动平衡队伍，保留复活。没有比赛时限，也不因分数或队伍离场结算。房间空置后保留入口并回收对局，下次加入重新创建对局。断线保留席位 30 秒供重连，过期释放。

普通自建房间仍保留原有开局和胜负规则。嵌入式测试服务可通过 startServer 的第六个参数启用公共房间，正式 server/main.ts 默认启用。协议入口为 joinDebug，仍校验客户端内容版本和昵称。

验证：room 单元测试覆盖单人控制、迟到参战、超时/超分不结算、连续离场席位回收；debug-room 浏览器测试覆盖服务启动注册、一键进入、切枪以及空房保留。
