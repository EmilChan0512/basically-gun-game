# 持刀、站立动态与隐匿被动

狙击职业沿用现有 `assassin` ID 和“刺客”显示名称，保留要害瞄准与两个可选主动技能，新增独立的隐匿被动。

- 地面连续站定 150 个模拟帧（5 秒）进入隐匿，站着或蹲着都可计时；瞄准转向不打断。
- 隐匿后蹲行保持，未隐匿时蹲行不能累计站定时间。站立移动、跳跃和攀爬打断。
- 实际射击、近战出手或成功开始换弹解除隐匿；换弹期间不计时，结束后重新等待 5 秒。空弹、无效换弹不会凭空产生攻击或换弹事件。
- 隐匿只影响敌方角色/标签/雷达可见性和 AI 感知，不删除实体或命中框。非致命受击不解除此被动；死亡、复活和调试重新配装清零。
- 沿用公开目标物规则：携带公文包期间不隐匿。本人和队友仍可看到角色，HUD 显示计时或“已生效”。
- 单机与联机共享规则。服务端过滤不可见角色的状态与姿态，客户端不能自行提交隐匿状态。计时写入检查点，可确定性恢复。内容规则版本更新为 24，需要匹配的客户端与服务器。

## 原作依据与动画适配

静态读取 `archaeology/local/script-pass/scripts/Guns.as` 的 `setFrame`，以及 `MBFZ_fla.arm_gun_316` / `arm_front_328` 时间轴，恢复 `knife`、`sword` 和对应 `*_fire` 的双臂、手掌与刀身变换。原作出刀片段从接触姿态开始，本项目保留已有 3/2/7、4/2/9 帧战斗节奏：前摇从待机姿态过渡到接触姿态，攻击窗口播放接触帧，随后重采样原作后续与归位姿态。插值按旋转与长度计算，避免大角度旋转时手臂缩扁。六把近战使用原作 SVG 局部坐标，不再用 PNG 裁边后的手工锚点举刀。

`UnitMC` 的 `idle`、`duckloop` 关节用于站立/蹲伏动态，放慢至原时间轴的三倍并插值。角色肢体、持枪手和枪口跟随肩部运动；脚部保留原作轻微重心变化。局内按模拟帧播放，配装页由同一姿态函数生成 CSS 动画（站立周期 2 秒），无常驻 JavaScript 定时器，并支持系统“减少动态效果”设置。

原作 `Status.as` 的 `stealthDelay` / `sInvis` 和敌我透明度逻辑作为机制参考；这里的 **5 秒站定、蹲行保持和受击不解除** 是本次需求规则，不宣称与原作数值一致。原有主动“暗影隐匿”的持续时间和受击解除规则独立保留。

新增矢量素材可复现：使用已校验的 FFDec 静态导出 `DefineSprite 375` 的 62—67 帧到 `archaeology/local/anatomy-export`，再运行 `npx tsx tools/archaeology/character-art.ts`。素材清单记录符号、帧号和 SHA256，没有执行原作脚本。

验证包括 `stealth.test.ts` 的计时/移动/战斗/可见性/AI/检查点回归、`character-pose.test.ts` 的关节与镜像回归，以及真实配装页动画循环、六种近战和盾牌十六方向浏览器检查。
