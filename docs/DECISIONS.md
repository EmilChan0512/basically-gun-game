# 实施记录

## 2026-09-09 Phase 0

- 按计划第 15 节限于考古工具链和下一阶段 Movement Lab；不一次性生成完整游戏。
- 没有原版 SWF；允许手动回退的工具验收可运行，但“发现原版包/类”和“首批已验证历史值”仍待真实输入，不能伪造。索引合成样本仅用于测试。

- Phase 1 仅作为可调实验设施，参数为 TUNED；原版还原度验收必须等待参考证据。这是无参考输入条件下的明确限制。

## 2026-09-09 Phase 1 与验证

- 直接使用 Phaser 3.90、TypeScript 和 Vite；未接 OpenGame 服务，没有引入未来战斗系统的空模块。
- Phaser 的自动物理循环与手动 120 Hz 循环不能叠加。通过 disableUpdate 禁用自动更新，每步明确 preUpdate、控制、resetFlags、step、postUpdate，实际浏览器测试验证 30/60/144 Hz 显示条件下一致。
- 台阶前探增加空间占用检查，18 px 默认上限拒绝 28 px 台阶；单向平台用下降方向、上步脚底和下穿计时器过滤。
- 所有 14 个初始运动参数进入 TUNED 证据记录；测试防止配置与证据库漂移。
- 将 Vitest 升到 4.1.11 修复依赖审计问题。npm 10 在更新可选 peer 图时出错，更新时采用 legacy-peer-deps，随后普通 npm ci 已验证成功，无需用户设置全局 npm 选项。
- 验证结果：14 项规则/工具/证据测试、7 项 Chromium 游戏集成测试通过，TypeScript 和生产构建通过，npm audit 0 vulnerabilities。
- Phaser 独立 vendor chunk 约 1.21 MB（gzip 332 KB），构建给出体积提示；这是当前完整引擎体积，不影响本地移动实验室验收。以后有真实性能需求时再评估定制引擎构建。
