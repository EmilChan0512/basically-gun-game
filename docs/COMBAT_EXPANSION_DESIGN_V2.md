# 《破晓行动》战斗系统扩展策划案 v2.1：四干员专属装备版

日期：2026-09-13。状态：策划与开发输入；新增数值为首轮验证基线，实现状态见[开发执行与证据](COMBAT_V3_IMPLEMENTATION.md)。

配套：[带数值的开发规格 v1.0](COMBAT_DEVELOPMENT_SPEC_V1.md)。本文件定义方向与范围；开发规格定义字段、数值、计算顺序和验收预期，具体实现以同版本开发规格为准。

## 1. 本次调整结论

**只保留现有四名干员：突击兵 Assault、重装兵 Tank、狙击手 Sniper、医疗兵 Medic。** 保持现有ID和四种职业形象，不新增先锋、工兵、讯鸦等独立干员，不再建立“职业下面再选角色”的层级。

每人1个固定被动、2个战前可选E技能、3个本干员专属G道具、1个固定觉醒、12张成长卡和2条进化路线。**G不是共享装备池，每人只能三选一装配自己的道具；其他干员不可装备、拾取或复制。** 地图基础弹药补给仍对全队开放，它不是G道具。

原v2.0的十二干员方案、通用战术道具池和六干员首发计划全部由本版替代。部署防守归入重装兵G，电子侦察归入狙击手G，救援与补给归入医疗兵G，破阵爆炸归入突击兵G。

本版规模：**4干员、8E、12专属G、4被动、4觉醒、48普通成长卡、8进化卡、12基础Perk**。枪械和配件保持深度，目标18枪、36配件，首批10枪、18配件。人物层级与Perk数量收敛，丰富度集中到四种职责内部。

## 2. 立项时基础与设计边界

立项时成长模式已有四职业、六主武器和USP、四种E、每局四次三选一、三Perk槽、单件改装、独立账号成长和服务端校验。四职业HP为100/115/90/95，速度倍率为1.0/0.9/1.0/1.0，本版沿用。本节描述改造起点，当前开发状态见执行记录。

立项时GrowthLoadout尚无可选E和专属G字段，不能只改界面；通用手雷计数、grenadePouch发放、机器人投掷路径也要改造。旧Arsenal的弹丸等数据读取经典目录，成长武器扩展须同步解耦。

以成长PvP的2v2～4v4为主要目标，单人机器人训练使用同规则。经典、战役、经典刀盾与账号资产维持独立。本文件定义设计范围；后续已获授权的开发与发行按配套规格和执行记录推进。

依据：src/shared/content/GrowthCatalog.ts、GrowthCareer.ts、GrowthRecords.ts；src/shared/simulation/GrowthCombat.ts、GrowthMedic.ts、RevealPolicy.ts；src/game/campaign/Arsenal.ts、Battle.ts；src/client/presentation/Gunsmith.ts。历史README和阶段测试数量不作为新版本验收结果。

## 3. 四名干员职责与装备

| 干员 | 职责 | E二选一 | G专属三选一 | 价值 / 弱点 |
| --- | --- | --- | --- | --- |
| 突击兵 | 推进、破阵、收尾 | 战斗翻滚 / 突进装填 | 破片雷 / 震荡雷 / 定向爆破包 | 逼位与突击；缺乏团队治疗和主动侦察 |
| 重装兵 | 抗线、掩护、守点 | 装甲屏障 / 定向战术盾 | 折叠掩体 / 投掷拦截器 / 应急装甲包 | 吸收压力、分割枪线；移动慢、怕侧翼 |
| 狙击手 | 精确射击、侦察、反部署 | 精准专注 / 战术转移 | 侦察信标 / EMP弹 / 声光诱饵 | 发现时机与拆解阵地；低血量、近身容错低 |
| 医疗兵 | 恢复、救援、补给 | 急救脉冲 / 持续治疗链 | 救援烟雾 / 急救站 / 弹药投送 | 维持战线；直接爆发少、治疗可被压制 |

保留E/G/Q/R与移动射击操作，不增大招键。E走冷却，G走有限次数；觉醒到时自动开启。每队允许重复干员，推荐一突一重一狙一医但不强制，2v2不必凑齐四职业。重复护甲、持续治疗和侦察不叠收益。

正式对局开始后锁定整套配装，复活不能换职业补道具。调试房间保留测试能力，但记录与正式成长结算隔离。

### 3.1 突击兵

翻滚保留0.4秒加速50%、8秒CD、期间禁火；突进装填提供0.6秒加速25%、将4发备弹转入弹匣、11秒CD。两者不穿墙、不无敌、不生成弹药。

破片雷负责直接逼位，震荡雷负责短时减速，定向爆破包针对部署物；均有可见轨迹或武装预警。觉醒保留击杀回血与短时加速的推进风格，不加永久伤害。

### 3.2 重装兵

装甲屏障允许减伤同时开火；定向盾更强地保护正面，但禁火、有吸收预算。首期成长副手统一为枪械，不叠加经典副手盾。

G决定团队贡献：掩体阻挡双方子弹但不挡人物；拦截器可射毁或被投掷物消耗；装甲包用于有限次数自保。没有无限耐久或可无限维修的阵地。

### 3.3 狙击手

精准专注用站位换精度；战术转移用于暴露后换位，期间禁火。保持场景可见，不引入完全隐形、瞬移或穿墙索敌。

信标只报告视线可达目标的最后位置；EMP只停机部署物，不禁玩家开枪；诱饵制造声音和雷达误判，无直接伤害。信息工具与精确枪械共同形成职业特色。

### 3.4 医疗兵

急救脉冲适合跟队推进；治疗链持续保护单个队友，但不能同时开枪。医疗兵G提供队伍唯一主动烟雾来源，也可改选固定急救站或弹药箱。

治疗量和治疗经验分开结算，自疗、友伤、环境伤、超量治疗不刷经验。首版保留死亡后复活，不加入倒地扶起，避免重写计分与生命流程。

## 4. 专属G的资源与反制

每人只装备一种G；不同道具初始1份或2份。死亡、重连、换枪、治疗、地图补给均不补G，下一局才重建。每名干员有一张卡每局最多增加1份已装备专属G；不能解锁、复制或补充其他干员的G。

G不自动回充，两次成功使用有最短间隔。部署物数量受限，不能靠反复回收获得免费使用次数。专属道具的全部初始份数、施放时间、范围、伤害、寿命、血量、失效条件见开发规格。

所有强效果必须有通用反制：离开爆炸范围、绕盾、射击拆除、换线或等待效果结束。其他干员的专属装备可加强反制，但不应成为唯一解法。

## 5. 枪械与配件

目标18个原型：3突击步枪、3冲锋枪、3霰弹、3精确武器、3机枪、3副武器。首批为现有六主武器+USP，加三连发步枪、DMR、左轮，共10把。

成长配置独立承载伤害、节奏、弹丸、衰减和散布，不继承经典武器等级。开发文档给出18枪完整基础参数，不把同枪换皮计为新玩法。

枪匠六槽为枪口、枪管、握持、枪托、供弹、瞄具，每槽六件，共36件；主武器最多3件、副手最多1件。先交付枪口/枪管/供弹18件。每件具有收益与代价，不能改基础伤害、爆头倍率、射速。扩容不增加整枪总携弹量；瞄具不扩大网络可见范围。

## 6. 成长构筑

每人12卡：4行为卡、3张E-A卡、3张E-B卡、2张本干员G卡。选E后9卡合法，战前选8张，局内四次三选一。G卡对本干员三种G均有定义，避免EMP配装抽到“信标加血”死卡。

每人2条E进化，共8张；第4次选择时，满足当前E的两张指定前置，候选保证包含相应进化，占用正常选择。不靠连杀解锁，不额外送第五张。

Perk收敛为机动/操控/生存三组，各4项、每组选1，共12项；不提供跨职业G、额外G充能或主动技能复制。

首轮保留15分钟、当前经验阈值和第12分钟觉醒，先隔离验证技能与专属装备。10分钟/第7分钟觉醒仅作为后续独立实验预设。竞技成长战斗选项全开放，长期成长用于外观、称号与预设；经典许可证与职业等级不变。

## 7. 八条推荐玩法

| 干员 | 路线 | 配装示例 | 循环 / 弱点 |
| --- | --- | --- | --- |
| 突击兵 | 近身突破 | 翻滚、MP5短枪管、破片雷 | 投雷逼位→翻滚过口→近身输出；远距弱 |
| 突击兵 | 持续破阵 | 突进装填、M4快拆弹匣、爆破包 | 拆设施→移动装填→换位；小弹匣与CD空档 |
| 重装兵 | 据守火力 | 屏障、SAW、掩体 | 分割枪线→屏障射击→退掩体；怕侧翼与拆除 |
| 重装兵 | 团队推进 | 定向盾、霰弹、拦截器 | 拦投掷物→举盾过口→队友接枪；自身禁火 |
| 狙击手 | 阵地射手 | 专注、Scout精密枪管、信标 | 观测→专注→换角度；容易被绕近 |
| 狙击手 | 机动反制 | 战术转移、DMR轻型枪管、EMP | 停机→补枪→转移；技能不直接加伤 |
| 医疗兵 | 跟队救援 | 脉冲、FAMAS、烟雾 | 烟雾切线→群疗→转点；G有限 |
| 医疗兵 | 阵地续航 | 治疗链、M4、急救站或弹药箱 | 固定恢复/补弹→保队友；引导时难自卫 |

## 8. 平衡和UI

伤害、护甲、减伤、加速、换弹与冷却统一解析，禁止多模块各乘一遍。临时护甲不叠加、不用低护甲延长高护甲；持续治疗取最强，重复干员不产生无敌组合。

配装页面依次选择四干员之一、E、本干员G、主副枪、配件、Perk、卡池。G页只显示该干员三项；切干员加载其已存合法预设，没有则用默认，绝不保留上一干员G。

HUD显示E冷却、G图标和剩余份数、弹药；用尽仍显示“本局已用尽”。烟雾在服务端遮断观察，死亡回顾不暴露隐藏敌人。地图须至少两条入点路线，部署禁区保护出生位置与必要交互点。
