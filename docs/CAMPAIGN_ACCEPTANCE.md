## 测试结果

- `npm run check`：104个单元用例全量通过，63条证据校验、资产隔离、TypeScript与生产构建通过。随后新增机器人返补给用例，定向 `campaign.test.ts` 18/18通过；当前105个不同单元用例均已本轮验证。
- `npm run test:gameplay`：22/22通过，45.8秒。包括三个战役流程用例和19个已有训练场用例。
- `npm run test:offline`：2/2通过，2.6秒。实际运行可复制包里的服务器；限制请求仅能访问127.0.0.1，验证菜单、部署、真实鼠标开火、暂停恢复、生产环境无开发调试对象，以及文件/方法边界。
- 通关模拟通过合法的玩家移动/瞄准/射击/切枪输入推进Battle，不改分数、HP、位置或AI来伪造胜利。轻松和标准难度各四关纳入单元回归。另做10个种子×4关轻松难度诊断，40场全部通关。
- 浏览器四关测试使用同一合法输入策略加速逻辑更新，并实测下一关、关卡锁、刷新读档与最终结局。独立的浏览器用例通过真实键鼠验证运动、短按跳跃、射击、换弹、切枪、暂停和失焦。
- 第一次真实输入测试发现短按跳跃在两帧之间被漏采，已修正为仅缓存到下一逻辑帧的跳跃事件；复测及全量回归通过。
- 无为通过测试而降低游戏目标分数、去掉AI或修改伤害；规则隔离单测中有明确标注的fixture位置/HP设置，仅用于生命周期和计分边界。
