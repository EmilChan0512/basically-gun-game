本机账号是设备内档案的登录入口，不是服务器身份认证或跨设备云账号。文件/浏览器存储可被设备使用者管理，清除网站数据会丢失档案。没有收集邮箱或发送密码到远端。

## 玩法设计

职业基础HP为85/70/100/130，瞄准为0.7/0.95/0.6/0.55，弹药倍率为0.9/0.75/1.3/1。医疗兵较早开始回血，刺客头部伤害提高25%，突击兵携弹更多，重装兵减免30%爆炸伤害。训练可加生命或瞄准。

技能分别为：战地急救/再生组织、精准专注/暗影隐匿、弹药补给/火力压制、装甲屏障/钢铁意志。每职业第二技能在Lv2解锁。持续效果覆盖完整配置逻辑更新数，包括最后一帧；暂停冻结计时，死亡清除持续效果但保留剩余冷却。

初始350军资，默认M4+USP、急救包。Vector与弹药包Lv1可购买；霰弹、Beretta和手雷Lv2，Dragunov与SAW Lv3。武器/道具解锁账号共享，装备仍需当前职业等级。每160经验升一级，最高Lv10；每升一级获得1训练点，两项训练各最多3级。

胜利基础130经验/180军资，失败35/40；每次个人击杀加10/12，奖励计入的击杀上限30；首次完成额外80/100。正常结束才结算，主动返回菜单或重试未结束的战斗不发奖励。战斗使用出战时的配装副本，战斗中不可打开军械库修改属性。

## 参考资料与边界

仅查看已在本地的静态资料，没有运行老游戏或逐帧读取：

- Stats_Classes.as:53、74、95、110：Medic、Assassin、Commando、Tank及初始属性方向。
- Stats_Skills.as:92—169：战斗/精准/弹药/防护、回血、暗影等技能描述。
- Stats_Guns.as:205、212、832、975：Beretta、Vector、Dragunov、Saw武器类别与配置线索。

新技能主动化、经验速度、金币、解锁等级、枪械平衡和投掷物都按本项目四关战役设计。没有复制反编译代码/美术进入产品，也未将新增设计标为原版EXTRACTED或OBSERVED。既有63条证据保持原分类。

## 测试与产物

本轮 `npm run check`通过133个单元用例、证据校验、研究资产隔离、TypeScript与生产构建。`npm run test:gameplay`全量25/25通过（54.3秒），`npm run test:offline`生产包3/3通过（4.1秒）。生产测试包含本机账号注册、购买、职业技能、刷新恢复及外网请求为0。

关键测试：

- Accounts：密码错误、同名注册、随机盐、不保存明文、退出会话、账号隔离、旧存档只迁移一次、存储失败不创建已登录账号。
- CareerProgress：实际终局结算、重复领取、读档去重、等级和资金不足拒绝、职业独立成长、训练/配装落盘、异常存档校验。
- Battle/Arsenal：所有职业可通关、所有武器实际伤害、霰弹粒数、全部技能效果、持续帧边界、死亡重置、道具次数、手雷地形遮挡、暂停不消耗技能道具。
- 浏览器完整流程使用普通输入策略赢得关卡，没有改分/HP伪造奖励；随后真实点击升级和购买，再实际按E/G验证新配装进入战斗并落盘。

军械库和配装战斗截图在 `artifacts/qa/career-armory.png` / `career-battle.png`。离线目录仍为 `artifacts/project-strike-local/`；默认本地地址仍用4175，便于保留上版存档来源。运行需本机Node.js20+。
