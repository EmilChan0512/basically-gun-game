# 《破晓行动》四干员战斗系统开发规格 v1.0

对应策划：[v2.1四干员专属装备版](COMBAT_EXPANSION_DESIGN_V2.md)。日期：2026-09-13。

**状态：开发数值基线，不是现有实现说明或已验证的平衡结论。** 已实现范围及验证证据见[开发执行记录](COMBAT_V3_IMPLEMENTATION.md)。本文明确给出首批及后续装备参数；P5枪械/配件随阶段开关上架，不能提前出现在正式配装池。只适用成长规则，不替换经典规则。

## 1. 范围、单位和执行约定

### 1.1 范围清单

- 保持`GrowthClassId = assault | tank | sniper | medic`，不新增独立operatorId、角色选择层或职业。
- 4被动、8个E、12个专属G、4觉醒、48普通卡、8进化卡、12 Perk。
- P2共10枪、18配件；P5共18枪、36配件。主武器3件、副武器1件，每槽最多1件。
- 每人一个E选项和一个G选项；本局锁定。G不可跨职业、不可拾取、不可交易、不由地图箱/治疗/击杀刷新。
- 保持复活150tick、出生保护75tick；出生保护期间不允许发动E/G或攻击，按攻击输入立即结束保护后才按正常准备时间攻击。经典生命周期独立保留。

### 1.2 单位及确定性

| 字段 | 定义 |
| --- | --- |
| tick | 固定30Hz；1tick=1/30秒。持续区间为[startTick,endTick)，到endTick立即失效 |
| HP | 内部整数毫血mHP，1HP=1000mHP；每次最终伤害四舍五入到mHP；UI血条按精确值，数字向上取整到HP |
| 时间倍率 | 以整数基点bp表示，10000=1.0；所有耗时最终ceil到tick，最低1tick |
| 位置 | 世界像素px；沿用现有移动碰撞。技能范围用角色胸部中心(x,y−33)，蹲伏用(x,y−22) |
| 角度 | 角度单位度；模拟角度可用现有弧度接口适配，所有随机数取共享可复现随机源 |
| 输入 | E/G/Q使用按下边沿；半自动使用射击边沿；自动使用持续按住。不重复消费同一输入seq |
| 就绪 | 在tick t发起，前摇c，成功生效t+c；CD从成功生效计，readyTick=t+c+CD |

每tick固定顺序：失效状态/冷却与复活 → 校验输入与开始/完成施法 → 移动/投掷物移动 → 拦截判定 → 射击和到期爆炸/直接伤害 → 治疗脉冲 → 击杀、贡献、觉醒衍生效果 → 快照。攻击者在伤害阶段开始时存活且已发出的攻击可形成同tick互换；被本阶段杀死的目标不接受随后治疗。阶段内按事件序号、actorId和实体ID稳定排序，不依赖Map插入偶然顺序。

E/G前摇互斥；先处理E，成功接受E则同tick的G返回busy，不消耗。E进入持续阶段后是否允许G按技能禁G标记决定，不把整个E持续期一概锁死。按Q中断换弹，保留已有射击间隔；不能通过切枪/施法缩短shootReadyTick。死亡中断尚未成功的施法；若弹药、G或CD已经提交，则不退还。界面预览只读，不执行上述事件。

特殊规则：

1. md_pulse在接受及成功时两次验证，若生效时全满血/无目标，返回no_effect、不进入CD；前摇期间的操作锁自然结束。
2. md_link根据鼠标选择：友方胸部距瞄点≤48px候选中最近者，再按actorId；无候选且自己受伤则自用；只能选非满血目标。生效时再次校验。
3. 治疗链每跳重新检查存活、同队、距离≤240、实心墙与烟雾视线。失效立即结束，不跳转目标、CD保留；施法者受到>0敌方生命伤害即中断，护甲完全吸收不打断。目标受伤不打断。
4. 第一次链治疗在生效后15tick，后续30/45/60/75/90；末跳在结束清理前显式执行一次，不能因半开区间少跳。持续治疗被同类更强效果抑制时仍推进计时但不发治疗/经验；采用§7.3的有效源仲裁，不把错开的多个治疗源轮流叠加。
5. 定向盾面对来弹方向由伤害origin→目标胸部向量确定；爆炸也以爆心判定，环境绕盾。若伤害100、预算剩20，则最多挡20、余80继续个人减伤/护甲；预算为0立刻收盾。
6. 持续E再按E可主动结束（翻滚/突进装填不允许取消）；无冷却返还。治疗链结束恢复射击有6tick准备期，盾收起有6tick；其他E无附加后摇。减CD卡不修改已经开始的CD。
7. sn_relocate可换枪/换弹，但切枪准备期和前15tick禁火取较晚结束时间；不能以Q规避禁火。

## 4. G专属道具：权限与资源

### 4.1 消耗、投掷、部署公共规则

G使用固定初始库存，不自动充能；`itemCharges`成功提交时减1，死亡和重连保持。全局成功G间隔至少30tick；遥控二次引爆是已有实体操作，不耗库存。单人同时存续部署物最多1个，新部署时若旧物仍在则拒绝existing_deployable，不消耗；全局最多8个（最大8玩家），实体生成顺序确定。

部署物计数包括掩体、拦截器、信标、爆破包、诱饵、急救站和弹药箱；诱饵释放前即预留自身部署槽，落地失败/被拦截释放预留。烟雾区域独立全局最多8个，飞行G最多32个；烟雾投掷接受时预留区域槽，被拦截释放，成功成烟接续占用；超限拒绝不消耗，避免已扣份数却无法生效。库存最大3，G1只在本局首次成功选择时执行一次。

投掷：前摇6tick、结束后禁火6tick；出生点取当前枪口外合法位置，初速度vx=cos(aim)×13、vy=sin(aim)×13−5，重力+0.5px/tick²。墙壁水平反弹vx×−0.5；落地vy=−abs(vy)×0.4、vx×0.8；abs(vy)<0.5且贴地则vy=0。倒计时从释放起计，不允许捏雷。半径2px，分步位移每步≤2px，避免穿窄墙。瞄点非法/NaN/出图时拒绝。

部署：前摇12tick、后摇6tick，需落点距胸部≤80px、地面支撑、放置矩形不与实心墙/既有部署物重叠，且距所有出生点≥120px、任务必要交互点≥60px。生效时重验，不通过不消耗；地图在配装前标注部署禁区。部署物无爆头、无护甲，不拦角色，不被治疗链/脉冲修复，无手动回收退款。

自用：按各项前摇生效，前摇禁止射击/G/Q和开始换弹；受敌方生命伤害中断、不耗份数。G可在普通移动中使用，前摇移速×0.75。接受G取消正在换弹的流程，不退已完成装弹；E有禁G标记时不得使用。

队友可受到友方医疗/补给，但不能拿到原道具物品。友方部署物不可被友军伤害；爆炸不伤队友，拥有者承受自身对人爆炸伤害50%，自伤无经验。EMP只停机敌部署物。死亡保留已释放投掷物和已生成设施至到期；主动离场清理本人部署物，已释放投掷物保留source参与记录直到结算；下一局全清。

精确补充：

- 爆炸距离用爆心到胸部；无墙遮挡且d≤R才命中，伤害`Dmax−(Dmax−Dmin)×d/R`。部署物使用其中心距离。范围增益只改R，不改伤害和每秒效果。
- 拦截器拦截破片/震荡/EMP/诱饵/烟雾的飞行实体，不拦子弹、部署爆破包或已生效烟雾。每tick先按“距拦截器距离、实体ID”选一个，消耗1次容量；若同tickEMP进入有效拦截区且引爆到时，先被拦截。已有EMP停机状态的拦截器不能工作。
- 电子标签仅为拦截器、信标、诱饵、急救站；掩体、爆破包、弹药箱不受EMP停机。停机期间不扫描/治疗/发声/拦截，寿命继续；恢复时按原时间轴下一次触发，不补发遗漏脉冲。多个EMP只取更晚的到期，不相加时长。
- 急救站首次治疗于工作后30tick；按HP比例从低到高、actorId排序分配预算，每目标每跳最多3HP，最后不足3可给剩余；抑制、满血和遮挡不耗预算。总预算耗尽立即移除。自疗消耗预算但无XP。
- 弹药箱自动检查范围；满备弹不标记领取，实际补到至少1发才登记。箱子不能补G、E或其他箱子，单人每箱一次记录用参与者ID，死亡/重连不清。
- 烟雾若任意观察者→目标胸部线段与烟圆内部相交，则该观察者不能提供该目标场景可见性；友军自身信息保留。半径48px内不因烟显示敌人，统一阻断避免两套例外。多烟取遮蔽并集；实心墙仍优先。医疗脉冲为区域救援，不依赖目视选人，只被实心墙阻断；治疗链、急救站和信标依赖观察，因此受烟阻断。
- 信标不得上传隐藏目标实时坐标；每次合法扫描只生成当前位置快照，30tick后消失，不额外显示角色模型。烟雾生效后不回收过去的已知位置，但不得再更新它。
- 诱饵雷达点每次停留15tick，声源和雷达位置固定为实体位置；不是把拥有者坐标复制给敌人。

### 6.1 计算顺序及限幅

1. 读取枪械基础值；验证槽位、件数、型号、阶段和互斥，非法整套拒绝。
2. 同一数值的全部配件百分比（含当前成立的条件）相加一次。S倍率≥0.70；g、Bmax倍率≥0.70；R倍率限定[0.70,1.25]；v限定[0.90,1.06]；L配件倍率≥0.70；P配件倍率≥0.65。正向代价不随收益触顶而删除。
3. M和T采用floor，M≥1且M≤T。R的三个端点同倍率缩放，保留浮点px并保持a<b<c；L/P先不取整。
4. 条件卡/Perk的散布收益取最小倍率，不互乘；配件效果已在第2步，不再作为一个条件重复乘。最终散布按§5.1下限。V收益倍率最低0.50，受击视觉收益取最强。
5. L的卡/Perk收益取最小，再乘所有明确的负面倍率；最终L≥基础L×0.60，ceil一次。移动：职业×持枪配件×技能强制减速×(1+最高加速)×(1−最高敌减速)，不让加速覆盖技能减速。
6. 普通加速上限20%；as_roll上限50%、as_reloadrush上限25%仅在对应技能持续内生效，其他加速取max不叠乘；减速上限25%。速度取当前手持枪修正，Q准备期间沿用新枪。
7. E的数值型CD调整先加总比例，改善最多25%，负面全部保留并ceil；事件返还后readyTick不得早于上次生效tick+基础CD×0.50。进化明确替换CD的技能以替换后CD为基础。G不适用CD缩减。

例：M4 B01+A01+M02：M=floor(30×.8)=24，T120，备用96；非空L=ceil(34×(1+.12−.25))=30tick；R倍率1.12，S=.96°，V=.96°，P=ceil(8×1.10)=9tick，持枪v=.96。再选战术换弹0.80，非空L=ceil(34×.87×.80)=24tick，不能以已取整30再乘导致另一结果。

## 7. 伤害、护甲、治疗和状态叠加

### 7.1 伤害管线

合法性/出生保护 → 单发或单丸基础伤害×距离倍率×头倍率 → 目标类型修正 → 方向盾 → 个人减伤 → 临时护甲 → 生命 → 贡献。距离≤a倍率1，a<d<b线性降至f，b≤d≤c倍率f；c外无命中。不使用旧随机射程±3单位。

个人减伤取当前最强，上限40%；定向盾与个人减伤合并总减免最高75%。计算盾拟吸收`min(D×盾比例,盾剩余预算)`；个人减伤拟减少剩余×个人减伤率；若两者合计>0.75D，只缩减个人部分。环境伤绕过方向盾、个人减伤和临时护甲，直接生命，不触发恢复/减CD/觉醒。友伤关闭，自爆按§4规则，无奖励。

SG单次扳机命中同目标的各丸伤害先分别按头/身和距离计算，再合并成一次伤害事件；盾/护甲消耗按合并伤害，受击低血触发只判一次，命中经验最多记一个目标事件。没有随机暴击。

### 7.2 临时护甲：单槽、无备用层

每人只有`armorRemaining/armorUntil/armorSource`一个槽，最多25HP。新护甲额度大于当前剩余额度：整体替换为新额度及其到期时间；等于：刷新为较晚到期；小于：忽略，不延时，不保存隐藏备用层。吸收后不自动恢复，结束清零。护甲包只有“生效时额度严格提升”才消耗，等额刷新不让其使用。

例如剩25护甲30tick，新10护甲120tick到来：仍25/30，不能变25/120；受伤后剩5时新10到来，则变10/120。死亡清护甲，相关触发CD保留。

### 7.3 恢复与控制

持续治疗（治疗链、急救站）每tick为每个目标只激活一个有效来源：从存活、未停机/暂停、合法连通且有预算的来源中，按“该目标当前单跳治疗量/间隔tick”最高优先，同速率按来源实体ID排序。排名用整数交叉相乘，不用浮点比较；临界低血加成按当tick计算。即使胜者该tick没有到治疗时刻，其他来源也不能趁空档治疗。

各来源保留自己的原始脉冲时间轴。胜者到点才治疗，且距该目标lastContinuousHealTick至少达到胜者的间隔；未满足则丢弃该跳，不延期补发。切换胜者不立即送一跳，败者脉冲仍消耗时间但不耗预算。这样两个错开5tick的治疗链不能轮流叠出双倍治疗。末跳tick的来源在本次治疗仲裁后再移除；满血、目标死亡或路径失效不执行治疗。

瞬时脉冲单独结算、不受持续治疗限频；所有恢复不超最大HP。急救站同一tick对多目标分配预算时按§4.2排序，预算不足时只消耗真正恢复量。单源无阻挡时治疗链精确6跳，和其他治疗重叠时可能少于6次有效治疗，这是预期行为。

自疗被动独立，不参与上述持续治疗选择，仍最多回到半血。对生命伤害的记录按实际扣血，护甲吸收不产生治疗额度。任意恢复消耗等量可治疗伤害额度，不能留给另一个医疗兵重复刷。

减速取最大≤25%，同来源刷新时长而不加深；结束后45tick内新减速倍率减半，持续时间不变。EMP只对电子设施；没有玩家沉默、硬眩晕或解除射击输入。死亡清临时效果，不清本局G库存、技能CD、一次性卡发放标志、领取账本或目标治疗经验预算。

## 11. 经验、贡献与模式参数

首轮规则：900秒=27000tick，觉醒21600tick；XP阈值0/200/450/800/1200，击杀100、最近240tick对目标造成有效生命伤害的其他攻击者助攻60。目标死亡同一人只能领取一份击杀或助攻。部署物击毁无击杀XP、不记击杀成长触发。

同一玩家额外支援XP共用每900tick最多60基础XP预算；以下治疗还有40的子上限。窗口按对局tick0固定分桶，死亡/重连不清，满窗额度不会顺延。追赶倍率：落后全场当前参与者平均等级≥2时，本次XP×1.10并round；先扣基础XP预算，再追赶，不能突破预算反复领取。

| 来源 | 数值与防刷 |
| --- | --- |
| 治疗 | 每实际恢复2HP有效敌方伤害=1基础XP；每目标所有医疗来源共用20基础XP/900tick预算，医疗兵另有40/900tick子预算。不是每跳触发900tick锁死；碎片mHP在同目标/同治疗者/当前窗口累计到2HP再发，窗口结束不足2HP余数清零 |
| 拦截 | 每枚敌投掷物10XP，同一实体一次，计入支援60预算 |
| 掩体吸收 | 每累计阻挡30HP敌子弹伤害给5XP；仅过去90tick内有一名其他存活队友在掩体80px内且射线确实会继续命中其身体时记额度，自己空放受击不刷 |
| 信息助攻 | 队友击杀当前或过去90tick被自己信标合法标记过的敌人，给20XP；若已领伤害助攻则不再给；同目标死亡同一人一次，计支援预算 |
| 补给 | 首版只记录补弹量不发XP，避免弹药丢弃/回补循环；待战斗消耗追踪落地再另开版本 |
| 据点 | 无敌争夺、本人存活在有效据点内，每30tick给2XP；每人每900tick最多60XP，独立目标预算。自己防守点被敌争夺时停止这一被动XP |

任何恢复都会减少可治疗敌伤额度（最低0）；复活清该额度但保留目标治疗XP窗口预算。目标预算与治疗者预算在同一权威事务内扣减，多个医疗兵不能各领20；满血、环境伤、自伤、自疗、友伤不给XP。窗口跨边界可用新预算，仍需新的实际敌方伤害额度，不为未获得XP的旧恢复补发。该规则替代当前版本“每目标治疗领奖后900tick锁定”，避免持续治疗首跳拿2XP后余下治疗全部失去贡献；需显式新规则版本与防刷回归。

地图得分继续由原模式规则结算；本版本不添加支援XP为队伍胜负分。15分钟/10分钟两种预设不会共用平衡日志，10分钟预设仅P5实验：18000tick、觉醒12600tick，XP阈值初期相同，不静默改默认房间。

## 12. 类型、服务端、网络与AI工作包

### 12.1 配装与权威状态

建议类型（开发接口，不表示源码已经存在）：

```ts
interface GrowthLoadoutV3 {
  classId: GrowthClassId;
  abilityId: GrowthAbilityId;
  gadgetId: GrowthGadgetId;
  primary: GrowthWeaponId;
  secondary: GrowthSidearmId;
  attachments: { primary: GrowthAttachmentId[]; secondary: GrowthAttachmentId[] };
  perks: [MobilityPerkId, HandlingPerkId, SurvivalPerkId];
  pool: GrowthCardId[]; // exactly 8, legal for selected E and class
  title: GrowthTitleId | 'none';
}
interface GadgetRuntime {
  gadgetId: GrowthGadgetId; charges: number;
  useReadyTick: number; activeEntityId: string | null;
  extraChargeGranted: boolean;
}
```

校验顺序：对象形状/未知字段 → class → E归属 → G归属 → 枪许可/阶段 → 配件兼容/件数 → Perk组 → 8卡合法唯一 → 称号权益 → room锁定状态。不能接受客户端自报charges/cooldown/health/entityOwner。

G指令不让客户端决定实际gadgetId：`{type:'useGadget',roomId,round,seq,aim:{x,y}}`，从连接绑定actor的锁定配装读取。无效返回错误码not_owner_class/no_charge/busy/not_ready/invalid_target/existing_deployable/room_locked；同seq去重，重复返回原确认、不重新生成。选择、刷新、配装保存沿用各自batch/revision防重放。

现有统一输入接口的落地映射（rules45）：G使用`input.command.actions=['item']`，`command.sequence`对应seq；E为skill，换弹为reload。首次接受及内容相同的重传均返回`{type:'inputAccepted',roomId,round,sequence}`。这是入队确认，不能提前推进客户端预测的已执行ack，也不表示施法成功；施放失败仍由权威战斗反馈。按公开字段值比较，不依赖JSON键顺序；同序号改内容返回sequence-conflict，未知字段仍先拒绝。接收记录保留整局并写入检查点，断线/死亡不清；重复确认不重新排队、不刷新超时、不累计操作贡献。旧局/外房请求仍先按roomId/round拒绝。经典输入继续原有过期序号规则。

检查点包括每把枪弹匣/备用/射击锁/三连发队列/散布状态，E施放进度/充能队列，G库存/实体/消耗标志及容量预留，HP及护甲槽，部署物HP/预算/到期/停机/owner，连续治疗有效源/时间轴/lastContinuousHealTick及贡献预算，最后位置标记到期，随机源。恢复不重复执行已结算投掷、补给或治疗。

### 12.2 可见性与呈现

服务端产生事件：abilityStart/End、gadgetReleased、deployableCreated/Damaged/Destroyed、intercept、smokeStarted/Ended、intelPing、heal、armorChanged。事件ID单调唯一，重复快照不重复音效。

隐藏敌人的实时坐标、HP、装备及技能CD不因信标/EMP/诱饵发送；intelPing只含当时点位、team和expiresTick，允许已过时点位留存。部署物也须按合法观察/已知标记发送，不能成为透视实体；己方部署物位置可一直显示。烟雾修改`RevealPolicy`和`VisibleState`，不能仅客户端盖图层。

四人美术直接复用现有职业形象；技能A/B靠HUD和施法特效区别，不创建八套角色。最小新资源：12个G图标、部署物五种可破坏模型（掩体/拦截器/信标/急救站/弹药箱）加爆破包/诱饵模型、盾前弧、烟雾和EMP范围、治疗链、四觉醒图标。听觉至少区分敌投掷预警、盾击、设施命中、EMP、治疗、G用尽。

听觉实施补充（2026-09-14）：地面非蹲伏移动每10tick发出一次脚步，基础半径240px；战术转移缩至120px，B3缩至60px。通用战术反馈半径480px、爆炸720px，诱饵使用其配置480px，枪声使用配件解析后的半径。此处为首轮听觉基线，不改变枪械伤害或视野。声音可穿墙和烟雾，但不因此显示角色。服务端在事件发生时冻结每名存活听者的粗略方向（左/中/右，水平差不足24px为中）及近/中/远（半径三等分）；正式消息只发当前听者的这三档距离、方向、音效类型及可选枪声外观ID，不发声源坐标、角色ID或其他听者列表。声音只用于播放，不生成额外雷达点。近/中/远音量倍率1/.65/.35，左右声像±.65；G用尽反馈仅本人可听。EMP爆发一次，即使没有电子设施被命中也有音画反馈。

### 12.3 AI阈值

| 干员 | E与G最低行为规则 |
| --- | --- |
| 突击 | 敌人在400px内且需穿枪线/自身HP<40时可翻滚；突进装填需弹匣缺≥4且备弹>0；投雷需合法可见敌落点且预测爆点距自身>80px；爆破包优先敌设施 |
| 重装 | 过去30tick受敌伤或两敌可见时屏障；朝主要威胁举盾；掩体只在合法目标防守位部署；拦截器需敌方有投掷活动；装甲包HP<70且无更高护甲时脱战用 |
| 狙击 | 目标≥300px且自身在地面稳定时专注；敌距<180或HP<35时转移；信标布置在可到达的交汇点；EMP至少影响1个可见电子设施；诱饵布在侧线 |
| 医疗 | 脉冲范围内队友缺血合计≥20，或自己HP<40；治疗链优先低HP且可连通队友；烟雾用于队友HP<35且正受火力；急救站需附近队友缺血合计≥25；补给箱需队友总弹药<基础T的30% |

机器人只读队伍合法感知信息，不能扫描全actor列表获得隐藏敌人后做最优决策。无效E/G不每tick重试：失败后至少30tick再评估。G有限，首轮阈值优先避免空投，不承诺最优战术。

设施射击补充：可见敌方角色优先；无角色目标时，选择队伍合法感知且自身实心墙/烟雾射线可达的最近敌方设施，等距按实体ID。沿用武器射程、弹药、射击节奏和难度反应延迟24/16/9tick；静态小型设施瞄准偏移为同难度角色偏移的10%，仍使用真实武器散布及弹道，不直接扣设施耐久。友方设施和隐藏设施不可作为目标，目标消失重新决策。

掩体选点补充：有可见主要威胁时，候选必须位于该威胁所在的水平方向，检查距自身40/55px的合法地面位置；威胁一侧无合法位置则保留库存，不在背后消耗掩体。无可见敌人时仅沿用据点附近防守条件；所有选点仍遵守出生点和任务交互点部署禁区。

信标选点补充：沿用地图作者提供的导航图。当前四张基础地图为双向通路，交汇候选定义为至少连接两条通路的内部节点，排除单连接端点。由距离自身最近的导航节点出发，按有向links遍历可达节点；最近节点以纵向距离×2选择，与现有导航一致。候选按胸部距离、节点索引排序，并逐项通过80px施放范围、视线、地面、出生/任务禁区及占位校验。当前无合法可达候选或无导航图时保留库存，不退回任意近地面投放。仍按30tick战术评估，不改变角色移动碰撞或地图导航边。

爆炸躲避补充：每tick读取队伍合法可见的伤害投掷物，仅考虑敌方或本人投出的物体；距离引爆≤18tick时，用现有弹体位置/速度及地图碰撞预测爆点。已武装且可见的敌爆破包也构成威胁。自身胸部距爆点≤爆炸半径+40px且实心墙无遮挡时优先躲避，暂停新E/G决策但保持普通射击及所有动作锁。左右各评估96px目标点，以最小爆炸净距较大者优先，平局向左；前方8/16/24px须无墙且地面有支撑，地图边缘保留14px。两侧均不可行时只请求普通跳跃，不修改物理或伤害。友军他人投掷物、EMP/烟雾等无直接伤害投掷物及隐藏威胁不触发此决策；这是一阶避险，不保证所有地形和交叉爆炸均可逃脱。
