# Phase 4：机器人与导航（已交付）

2026-09-11，随四关单人战役交付。实现在 `src/game/campaign/Battle.ts` 与 `Navigation.ts`，不使用运行时LLM或联网服务。

机器人使用与玩家相同的 OriginalMovement、GunController、Recoil 和 traceBulletLine。不会传送或改写位置来跨障碍；仅死亡复活使用出生位置重置。每关提供手工导航节点和连接，最短路径选下一节点，观察目标高差及前方墙体发出跳跃输入。地形同时参与视线和子弹采样。

状态包括推进、跳跃、交火、据点保持和返回补给。选择可见近敌，经过反应延时后分段射击；弹药不足时换弹或切枪，全部耗尽则回本方出生区补给。友军不阻挡本队子弹也不承受友伤。

轻松/标准/老兵的敌方反应为24/16/9帧，瞄准目标竖直偏移范围为±90/55/28像素，每12帧重新采样；队友用标准参数。各档生命和基础武器伤害一致。这些是项目调参值，不是原版提取事实。

测试证明高台可被实际运动穿越，闲置玩家可被敌方击败，弹药耗尽会回补给；四关在轻松/标准难度通过普通输入模拟通关。战役采用有限的小图，因此暂不需要通用地图寻路编辑器。
