## 联动示例与边界

- 翻滚突袭40% + 滚后稳定30% = 下一发总增伤70%；整次霰弹一起结算，不按弹丸反复消费。
- 满膛突进25%射速 + 流动火力30%射速 = 55%射速；突进杀阵25%伤害 + 流动火力40%伤害 = 65%增伤。
- 攻城盾牌120额外预算 + 加固盾面300基础预算 = 420；战争堡垒与移动堡垒组合减伤65%。
- 治疗链延伸12生命/跳 + 加速输注0.2秒/跳 = 每秒60治疗；稳定连接持续4秒，医疗伴随允许同时开火。每个目标仍只接受最强连续治疗源，不靠多链重复叠治疗。
- 所有补入弹匣的弹药从备弹转移，受弹匣容量约束。拾取与击杀补给才增加备弹，并受总容量约束。
- 总减伤65%、护甲40、冷却返还80%的上限保留；手动换弹最快为基础耗时60%。新版中心散布底线为基础10%，使15%倍率的狙击进化可以兑现。
- 卡牌与技能的生效快照在施放时锁定；选中进化不会改写进行中的技能、已经投出的道具或部署物。道具库存最多3，G1只增发一次，死亡和重连不会重发。
- 直接额外伤害加算，射速奖励加算；同类移速仍取最高。依赖有效敌伤治疗的奖励不能靠自伤或环境伤害刷取。
- 选卡显示卡名与进化提示，爆发期间显示强化光环。数值定位是强构筑版本，真人平衡仍以体验反馈继续迭代。
