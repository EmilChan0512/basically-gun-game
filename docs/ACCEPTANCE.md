## Phase 1

两场景、一个组合式 Soldier、Arcade 小碰撞体与独立视觉、键盘横移/跳跃、鼠标朝向、地面加速/空中操控、显式土狼时间/缓存、有限台阶辅助、调试 HUD、四站灰盒课程、复位、慢动作、暂停单步、实时调参及跳跃 JSON 导出均已实现。

验证覆盖：站立跳高度/顶点/滞空；方向反转和空中惯性；台阶空间限制与实际攀越；下穿单向平台和缺口复位；键盘、暂停和单步；固定步长一致性。截图经过检查。主观手感是否像原版仍需要实际对照。

2026-09-09 本机结果：Node 22.19，`npm ci` 成功；`npm run check` 通过，14 项测试；`npm run test:gameplay` 通过，7 项 Chromium 测试；`npm audit` 无已知漏洞。浏览器还覆盖了跑跳越过 180 px 缺口、空中反向、调参/复原、慢速、鼠标朝向及 JSON 下载。
