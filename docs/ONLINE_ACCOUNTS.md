# 联机账号与进度

`/?online` 为联机大厅，顶部「出战配装」进入独立页面 `/?online#loadout`。职业头像、角色持枪预览和当前装备集中展示；主武器、副手、职业技能和战术道具按分类陈列图片卡片，显示属性、解锁等级、购买价格及装备状态。分类切换和返回大厅保留当前配装，浏览器前进/后退支持这两个页面。

普通联机先注册/登录当前服务器的账号，选好配装后创建或加入房间。账号名2—24个字符，密码8—128个字符；不同设备使用同一账号可读取同一份服务端进度。本机战役账号和进度不导入联机。调试房间使用同一配装页即时切换，浏览配装时游戏输入归零；返回房间后恢复控制。普通对战进行中关闭配装入口。

## 进度与解锁

- 新账号350金币，四个职业均可选；每个职业从Lv.1开始，独立记录经验和配装。初始拥有M4、USP、急救包。
- 枪械与道具使用金币购买，账号内共享所有权，但使用时仍检查当前职业等级。军械库展示价格和解锁等级，购买永久生效。
- 每160经验升1级，最高Lv.10。技能及刀盾按目录中的职业等级自动解锁；刀仅限刺客、盾仅限重装兵。
- 普通对局在服务器模拟满30秒，且玩家发送至少30条有移动、蹲伏、跳跃、攻击或技能动作的有效输入后，结束时结算。仅空闲心跳不计参与。胜利130经验/180金币，其他结果35经验/40金币，每次击杀额外10经验/12金币，最多计30次击杀。经验归本局所用职业。
- 观战者、未参与操作者、30秒以内结束的对局和公共调试房间无奖励。掉线重连沿用原身份；同账号只能占一个房间席位。
- 奖励来自权威服务器的结果和击杀数；客户端不能上传金币、经验、等级或结算结果。同一房间实例/轮次只能结算一次。
- 大厅更换配装会取消准备；普通战斗中不能更换。调试配装不写入普通账号存档。

## 存储与部署

`server/main.ts` 使用固定目录中的 `accounts.json`。路径优先级为 `ACCOUNT_DATA_DIR`、systemd `STATE_DIRECTORY`、工作目录下的 `data`。默认测试用 `startServer()` 是内存库；需要测试持久化时显式传入文件库。

数据库保存账号密码的随机盐和scrypt验证值、会话令牌的SHA256摘要、金币、职业经验、配装、购买记录和结算标记。客户端只收到自己的公开进度字段。会话7天过期，退出登录撤销当前会话。账号数据库不得放入客户端包、Git或日志。

写入使用临时文件、fsync、原子替换；失败不会修改内存进度。启动遇到损坏的存档会报错退出，不会把旧档当作新账号覆盖。这个版本由**一个服务端进程独占一个数据库目录**，不支持多实例共享文件或水平扩容。

生产服务新增 `StateDirectory=project-strike`，systemd 创建 `/var/lib/project-strike`，权限0700。数据库独立于 `/opt/project-strike/releases`，发布、回滚和重启不会清空账号；活动对局仍不恢复。数据库文件权限0600。备份应限制访问并保留原权限；停服恢复备份后再启动，不要把旧发布包覆盖到数据目录。

已有旧服务由 CI 的一次性迁移步骤使用现有管理员 `SSH_PRIVATE_KEY` 安装固定的 accounts.conf 配置并 daemon-reload；不删除数据，不扩大日常部署用户权限。检测到StateDirectory已配置后，后续发布跳过管理员步骤。也可手动执行 `sudo bash deploy/enable-account-storage.sh`。

## 当前无域名的测试兼容模式

按当前测试部署要求，服务显式设置 `ALLOW_INSECURE_ACCOUNTS=true`，允许沿用 `ws://43.142.165.82:4180` 注册、登录、选择配装并进入普通联机。界面提示使用独立测试密码。账号仍由服务端验证，密码按scrypt保存；WS传输本身不加密。

服务器welcome消息声明兼容策略。客户端先验证协议与内容版本，再发送排队的登录信息；若服务器未开放兼容模式，客户端不会向公网WS发送账号密码或会话令牌。

以后提供带有效TLS证书的域名，通过本机反向代理转发至 `http://127.0.0.1:4180`，并把服务环境变量改为 `ALLOW_INSECURE_ACCOUNTS=false`，即可关闭降级。HTTP入口只跳转HTTPS、不转发WebSocket，客户端改填WSS地址。严格模式只接受本机代理连接，客户端伪造转发头不能绕过检查。

## 验证

单元/真实WebSocket测试覆盖账号隔离、规范化重名、错误密码、会话过期/撤销、原子写入失败、损坏存档、购买扣费、职业/等级限制、伪造结算、观战无奖励和幂等结算。

浏览器测试 `tests/gameplay/online-accounts.spec.ts` 覆盖进房前配装、购买、切换账号以及服务端重启后重新登录恢复进度；原有双人联机、刀盾、调试和重连用例仍在CI中执行。
