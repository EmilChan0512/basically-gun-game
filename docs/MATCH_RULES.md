# Phase 5：单人小队比赛规则（已交付）

2026-09-11。`Battle.ts`负责30Hz比赛时钟、敌我单位、伤害归属、复活、团队计分、据点、时限和终局冻结。关卡数据在 `Missions.ts`。

- TDM：击杀敌人给本队加1，重复命中尸体不重复计分。环境死亡给对方加1。
- DOM：终端水平85px、垂直70px范围内仅一方存活单位占据时，累计30帧得1分；争夺或无人时停止累计，已有不足1秒的进度保留。击杀本身不加据点分。
- 一方达到目标分即结束。超时比较得分；平局视为玩家任务失败。结算后模拟、计分与伤害停止。
- 玩家和AI均为85HP，基础伤害一致；出生保护75帧，死亡等待150帧后在第151次死亡更新复活，回血规则沿用基础模块。复活恢复武器/弹药并选本队最远离存活敌人的出生点。
- 不允许友伤。弹药有限，出生箱每300帧补充备用弹药，弹匣仍需正常换弹。复活时按住扳机会锁定，松开后恢复射击。
- 暂停/失焦会清空输入并停止模拟；新关和重试创建全新比赛，清空分数/死亡/弹药状态。本地进度只因胜利增加。

这些比赛参数属于自研短篇设计。静态参考入口 `Stats_Campaign.setMatch` 与 `MatchSettings.EnterFrame` 可见tdm/dom模式、团队得分与目标分比较，但反编译含残留，不把本项目具体分数、关卡数量或AI当成原版事实。
