# Project Strike · 破晓行动

新增独立 **PvP 成长对战**：联网大厅创建成长房间，单人直接开局自动补机器人，多人使用真人队伍。提供 Assault、Tank、Sniper、Medic 与七把独立平衡武器，支持团队交火和据点战。Lv1～Lv5 四次三选一、每局一次刷新，第12分钟开放职业 Ultimate；死亡保留成长，支持重连。独立账号/职业成长、三 Perk 槽、成长池、武器配件及成就称号由服务器保存，保留旧战役与账号资产。P1 已验收，P2～P5 的玩法与扩展验收仍在推进；详见 [实施与验收](docs/GROWTH_PVP.md)。需要配套服务端，公网未随本地发行更新。

全模式已加入原作音效和角色短句：54把枪械开火／换弹映射、刀盾、爆炸、技能、移动、目标及界面反馈；四职业原声配中文字幕。右下角“声音设置”可分别调整音效和语音并保存，全部素材离线随包提供。来源、重建与验证见 [音效与语音](docs/AUDIO.md)。联机需使用同一版本的配套服务端。

可单人单机游玩的四关原创短篇战役。在经典横版小队射击机制基础上制作，沿用已建立的30Hz移动、USP/M4、换弹与复活节奏。包括任务地图、简报、敌我AI、战斗、胜负结算、重试、逐关解锁、本地存档和结局。

现有联网账号、4 个职业、9 种技能、54 种枪械、12 种刀盾和 3 种道具。主武器按原作职业和等级成长，职业上限 50 级。联网账号的金币、等级、购买许可证和配装由服务器管理；单机免登录，离线存档独立。详见 [服务端资产](docs/ACCOUNT_ASSETS.md) 和 [原作武器成长表](docs/WEAPON_PROGRESSION.md)。

职业副手已扩展：刺客六种近战、重装兵六种盾牌，单机与普通联机均按各自的职业等级免费解锁，公共调试房间全部开放。Q切换副手，点击攻击挥刀、按住攻击举盾；盾随鼠标360度转向，正面减伤70%—90%，部分型号可反弹或防爆。规则与原版参考见 [职业副手说明](docs/OFFHAND_CLASSES.md)。

公共调试房间现支持实时切换职业、主武器、副手、技能与道具，选择后立即补满状态；E技能、G道具。无需退出或重新准备，正式对局仍只允许大厅配装。详情见 [调试房间](docs/DEBUG_ROOM.md)。

持刀与挥刀改用原作双臂和刀身关节，局内及出战配装 OPERATOR 预览加入呼吸动态。狙击职业（当前名为刺客）可在职业技能槽装配隐匿被动：站定5秒后敌方不可见，蹲行保持，射击/近战/换弹解除，仍可被击中；自身有半透明显示和进出隐匿渐变。规则与原作依据见 [隐匿与角色动态](docs/STEALTH_AND_ANIMATION.md)。

管理员可通过服务器 `/admin/` 后台搜索用户、调整金币与四职业等级、授予或收回装备，并查看修改记录。使用独立管理员登录，所有变更由在线账号服务验证并原子保存。详见 [管理后台说明](docs/ADMIN_PANEL.md)。

## 直接游玩

战斗反馈已升级：死亡击杀信息与 5 秒大字倒计时，2 秒后 Tab 观察队友/地图；方向受击、短促后仰与准星上跳、阶段状态和低弹药/无备弹提醒。换弹与击败语音仅在关键情况播放并限频。详见 [战斗反馈](docs/COMBAT_FEEDBACK.md)。

每次本地发行执行 `npm run release`，会自动生成并校验 **`artifacts/Project-Strike-Windows-latest.zip`**。这是给朋友分发的 Windows 64 位便携包：完整解压后双击 `PLAY.cmd` 打开联机大厅，或双击 `SOLO.cmd` 进入单机，浏览器自动打开。包内已带运行环境，无需安装 Node.js 或 npm；保持启动窗口开启即可。联机仍需要可用的配套服务器。

每次发行的独立版本保存在 `artifacts/releases/friends-<内容版本>-<时间>/`，不会覆盖旧版本；`artifacts/friends-latest.json` 记录最新包路径、版本和 SHA256。`package:game` 在 Windows 上也会自动生成此 ZIP。发行流程包含便携运行环境启动验证、ZIP 内逐文件校验和生产离线测试。

当前工作区已生成生产包，可运行：

```powershell
npm run play
```

打开 http://127.0.0.1:4175/ 。关闭命令窗口或Ctrl+C停止。需要本机已有 Node.js 22.12+。默认进入联网大厅；点击“单机免登录”或打开 `?offline` 可完全离线游玩并保存本机战役。联网账号需要连接服务器，资产可跨设备登录读取。

可复制的离线包位于 `artifacts/project-strike-local/`，Windows双击其中的 `PLAY.cmd` 后打开上述地址。这个目录包含生产资源、本地服务脚本和第三方许可，不需要项目源代码或 `node_modules`。更换浏览器、主机名或端口会使用另一份本地进度。

开发运行使用 `npm run dev`；重新生成离线包使用 `npm run package:game`。首次开发安装需 `npm ci`。不要直接双击HTML：浏览器需要本地HTTP服务加载模块。

## 关卡

| 关卡 | 模式 | 目标 |
| --- | --- | --- |
| 失联信号 · 沿岸研究站 | 1对1团队交火 | 先获4次击杀 |
| 炉心回声 · 废弃铸造厂 | 2对2团队交火 | 先获8次击杀 |
| 静默频段 · 山顶中继站 | 2对2据点争夺 | 先获35控制分 |
| 破晓行动 · 撤离平台 | 3对3团队交火 | 先获12次击杀 |

击杀模式计算全队分数；据点模式仅在无敌人争夺时每秒加1分。时限到达时领先者获胜，平局判任务未完成。阵亡可复活，失败可重试或回地图调整难度。三档难度改变AI反应和瞄准误差，不暗改伤害。

| 操作 | 输入 |
| --- | --- |
| 移动 / 跳跃 / 蹲伏 | A/D或左右方向键 / W、↑、Space / S、↓ |
| 瞄准 / 射击 | 鼠标 / 左键或F |
| 切枪 / 换弹 | Q / R或L |
| 职业技能 / 战术道具 | E / G |
| 暂停和恢复 | Esc或P |

青色为友军、橙色为敌军，玩家服装颜色随职业变化。出生保护约2.5秒，死亡后约5秒复活。两把枪弹药独立；回出生区补给箱可补备用弹药，每10秒一次。若复活时一直按着射击，先松开再按。胜负结算自动保存奖励，胜利解锁后续关卡；切换职业不会丢失原职业成长。道具每次出战2份，复活不补充。
